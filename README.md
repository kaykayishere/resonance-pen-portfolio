# RESONANCE — Industrial Design Portfolio

A responsive, single-page portfolio website for the Resonance pen concept.

## Files
- `index.html` — complete website (HTML, CSS, and JavaScript)
- `assets/pen-prototype.jpg` — your uploaded physical pen photo
- `assets/music-pen-reference.png` — music-inspired reference image (kept in the project assets)
- `assets/moodboard.png` — your uploaded color mood board

## Preview locally
Open `index.html` in a browser. An internet connection is needed for the Google Fonts; the rest of the page works locally.

## Publish with GitHub Pages
1. Sign in to GitHub and click **New repository**.
2. Give it a name such as `resonance-pen-portfolio`. Set it to **Public** (or use a plan that supports Pages for private repositories).
3. Choose **Add a README** or create an empty repository.
4. Upload `index.html` and the entire `assets` folder. Keep the folder structure unchanged.
5. Open the repository's **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait a minute or two. GitHub will show the published URL in the Pages section. It will usually look like:
   `https://YOUR-USERNAME.github.io/resonance-pen-portfolio/`

Whenever you update the files and push/upload the changes to `main`, GitHub Pages republishes the site.

## Important content note
The page deliberately avoids inventing technical measurements, refill specifications, or mechanism details that are not confirmed by the supplied materials. Replace the placeholders in the Design Details section once you have measured and tested the actual pen.
